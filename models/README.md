# Models directory

This directory stores trained model artifacts and label files generated by the training pipeline. Examples include:

- `crop_model.keras`
- `class_labels.json`
- `{baseline,mobilenet}_class_labels.json`
- `{baseline,mobilenet}_config.json`
- `baseline_best.keras`
- `mobilenet_best.keras`

Do not store huge datasets or unverified model binaries here unless they are explicitly intended for the project. The app should handle missing artifacts gracefully.
