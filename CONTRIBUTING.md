# Contributing

Thanks for helping improve CropShield AI.

## Local setup

1. `py -3.13 -m venv .venv`
2. `.venv\Scripts\Activate.ps1`
3. `python -m pip install --upgrade pip`
4. `pip install -r requirements.txt`
5. Run tests with `pytest`.

## Workflow

- keep code modular and tested
- avoid hard-coded model scores
- document dataset or model availability clearly
- train/evaluate with a reproducible seed

## Pull requests

Include:

- summary of changes
- validation commands used
- note about dataset/model availability
- screenshots or app behavior summary when relevant
